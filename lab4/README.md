
# Лабораторна робота №4

Створення графічного користувацького інтерфейсу з використанням PyQt в Python.

У цій лабораторній роботі створено п'ять програм за допомогою Python та бібліотеки PyQt6.

## Завдання 1

Створення вікна з різними елементами інтерфейсу: кнопками, текстовими полями, списками, повзунком та іншими віджетами.

Файл: task1.py

## Завдання 2

Створення інтерактивної форми, яка реагує на дії користувача, перевіряє введені дані та дозволяє скинути форму.

Файл: task2.py

## Завдання 3

Створення текстового редактора з меню, панеллю інструментів, можливістю відкривати та зберігати файли.

Файл: task3.py

## Завдання 4

Створення двох компонентів, які обмінюються повідомленнями та оцінками за допомогою сигналів.

Файл: task4.py

## Завдання 5

Створення діалогових вікон для введення та підтвердження даних. Зміна зовнішнього вигляду програми за допомогою QSS.

Файл: task5.py

## Як запустити програми

Для виконання лабораторної роботи потрібно встановити Python 3 та бібліотеку PyQt6.

Встановлення бібліотеки:

python3 -m pip install -r requirements.txt

Запуск програм:

python3 task1.py
python3 task2.py
python3 task3.py
python3 task4.py
python3 task5.py

Для запуску п'ятого завдання без стилізації:

python3 task5.py --plain
